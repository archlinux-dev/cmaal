Fully local

One Node process, one JSON file. Your data never leaves your computer.

Up and running in three steps

  1. Create an account. Pick a username and password. It is stored hashed on your machine.
  2. Start a community. Give it a name and an emoji. You get #welcome and #general for free.
  3. Invite your people. Copy the invite code and send it. They join with one click.

A real API, right on localhost

Everything the app does goes through a JSON REST API you can script against.

curl -X POST localhost:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"you","password":"secret"}'

curl localhost:3000/api/communities -H "Authorization: Bearer $TOKEN"
